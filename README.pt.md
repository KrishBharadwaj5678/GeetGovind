# 🕉️ Geet Govind

Um aplicativo devocional desenvolvido em **Flutter**, dedicado ao **Shri Jagannath Ji**, com textos sagrados, imagens divinas e bhajans inspiradores. O aplicativo proporciona uma experiência espiritual tranquila e imersiva para os devotos.

![GeetGovindDemo](https://github.com/KrishBharadwaj5678/GeetGovind/raw/main/GeetGovindDemo.jpeg)

## ✨ Recursos

| Recurso                               | Descrição                                                          |
| ------------------------------------- | ------------------------------------------------------------------ |
| 🏠 Tela Inicial                       | Exibe o **Geet Govind** para leitura e devoção.                    |
| 🖼️ Galeria                           | Bela coleção de imagens do **Shri Jagannath Ji**.                  |
| 🎵 Bhajans                            | Coleção de **bhajans devocionais dedicados ao Shri Jagannath Ji**. |
| ▶️ Reprodutor de Música               | Player integrado para ouvir os bhajans.                            |
| 🎨 Interface Limpa                    | Design simples, elegante e fácil de usar.                          |
| 📱 Otimizado para Dispositivos Móveis | Desempenho suave em dispositivos Android.                          |

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia             | Finalidade                                                           |
| ---------------------- | -------------------------------------------------------------------- |
| 🐦 **Dart**            | Linguagem de programação utilizada no aplicativo                     |
| 💙 **Flutter**         | Framework para desenvolvimento de aplicativos móveis multiplataforma |
| 🎨 **Material Design** | Componentes e estilização da interface                               |
| 🎵 **AudioPlayers**    | Reprodução dos bhajans                                               |
| 🤖 **Android SDK**     | Compilação e execução em dispositivos Android                        |

## 🚀 Como Começar

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/GeetGovind.git
```

### 2️⃣ Acesse o diretório do projeto

```bash
cd GeetGovind
```

### 3️⃣ Instale as dependências

```bash
flutter pub get
```

### 4️⃣ Execute o aplicativo

```bash
flutter run
```
