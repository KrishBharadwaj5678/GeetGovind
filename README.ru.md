# 🕉️ Geet Govind

Духовное Flutter-приложение, посвящённое **Шри Джаганнатху**.
Приложение включает священные тексты, божественные изображения и проникновенные бхаджаны, создавая спокойную и вдохновляющую атмосферу для преданных.

![GeetGovindDemo](https://github.com/KrishBharadwaj5678/GeetGovind/raw/main/GeetGovindDemo.jpeg)

## ✨ Возможности

| Функция                                | Описание                                                      |
| -------------------------------------- | ------------------------------------------------------------- |
| 🏠 Главный экран                       | Отображает **Geet Govind** для чтения и духовной практики.    |
| 🖼️ Галерея                            | Коллекция прекрасных изображений **Шри Джаганнатха**.         |
| 🎵 Бхаджаны                            | Сборник преданных **бхаджанов, посвящённых Шри Джаганнатху**. |
| ▶️ Музыкальный плеер                   | Встроенный плеер для прослушивания бхаджанов.                 |
| 🎨 Чистый интерфейс                    | Простой, элегантный и удобный дизайн.                         |
| 📱 Оптимизация для мобильных устройств | Плавная работа на устройствах Android.                        |

## 🚀 Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/GeetGovind.git
```

### 2️⃣ Перейдите в каталог проекта

```bash
cd GeetGovind
```

### 3️⃣ Установите зависимости

```bash
flutter pub get
```

### 4️⃣ Запустите приложение

```bash
flutter run
```
