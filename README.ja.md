# 🕉️ Geet Govind

**シュリー・ジャガンナート神**に捧げる、信仰心あふれる Flutter アプリケーションです。
神聖な経典、美しい画像、そして心を癒すバジャン（宗教歌）を収録し、信者の皆様に穏やかで没入感のあるスピリチュアルな体験を提供します。

![GeetGovindDemo](https://github.com/KrishBharadwaj5678/GeetGovind/raw/main/GeetGovindDemo.jpeg)

## ✨ 主な機能

| 機能         | 説明                                 |
| ---------- | ---------------------------------- |
| 🏠 ホーム画面   | **Geet Govind** を閲覧し、祈りや瞑想に活用できます。 |
| 🖼️ ギャラリー  | **シュリー・ジャガンナート神**の美しい画像を収録しています。   |
| 🎵 バジャン    | **ジャガンナート神**への献身的なバジャン（宗教歌）を楽しめます。 |
| ▶️ 音楽プレーヤー | 内蔵プレーヤーでバジャンを再生できます。               |
| 🎨 洗練されたUI | シンプルで美しく、使いやすいデザインです。              |
| 📱 モバイル最適化 | Android デバイスで快適かつスムーズに動作します。       |

## 🚀 はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/GeetGovind.git
```

### 2️⃣ プロジェクトディレクトリへ移動する

```bash
cd GeetGovind
```

### 3️⃣ 依存関係をインストールする

```bash
flutter pub get
```

### 4️⃣ アプリを実行する

```bash
flutter run
```
